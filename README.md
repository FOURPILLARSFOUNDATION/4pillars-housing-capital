# 4PILLARS Housing Capital

Open-source policy research on homeowner liquidity, housing affordability, community wealth, and safe access to housing capital.

## Purpose

This repository develops evidence-backed policy options that expand financial resilience without turning homes into short-term speculative assets. Work is published as transparent drafts, with assumptions, distributional effects, legal questions, and implementation risks made visible.

## Initial questions

- Which homeowner-liquidity tools protect occupants and limit displacement?
- How can small investors participate without extracting value from vulnerable households?
- What guardrails reduce predatory lending, forced sales, and concentration of ownership?
- Which pilots can be evaluated publicly before wider adoption?

## Contribute
